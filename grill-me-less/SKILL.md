# Grill me less

Focus on the current task and ask only the most important questions, up to three in total. Make reasonable inferences yourself; there is no need to use all three questions. Ask one thing per question, and do not use subquestions to get around the limit. After asking, continue working with the information available. Only if missing information makes it impossible to proceed should you explain why and ask the user for permission to ask additional questions.
